# Clinic Management System 🏥

نظام شامل لإدارة العيادات الطبية، مصمم بأحدث التقنيات لضمان أداء عالٍ، وسهولة في الصيانة، وتجربة مستخدم ممتازة. ينقسم المشروع إلى واجهة خلفية (Backend) قوية مبنية بـ .NET، وواجهة أمامية (Frontend) حديثة مبنية بـ Angular.

---

## 🛠️ التقنيات المستخدمة

### الواجهة الخلفية (Backend)
- **الإطار العام:** .NET Core (ASP.NET Core Web API).
- **البنية المعمارية:** Clean Architecture (مما يسهل فصل الاهتمامات وتطوير النظام مستقبلاً).
- **النمط الهندسي:** CQRS باستخدام مكتبة **MediatR**.
- **قواعد البيانات:** Entity Framework Core (Code-First) مع SQL Server.
- **التوثيق والحماية:** ASP.NET Core Identity مع JWT Bearer Tokens.
- **التحقق من صحة البيانات:** FluentValidation (تحقق في طبقة الـ Application قبل الوصول للـ Database).

### الواجهة الأمامية (Frontend)
- **الإطار العام:** Angular (Standalone Components) أحدث إصدار.
- **مكتبة المكونات (UI):** PrimeNG.
- **التنسيق:** Tailwind CSS (مع تخصيص متوافق تماماً مع PrimeNG لضمان شكل احترافي و Responsive).

## 🚀 كيف تم التركيز على الأداء (Performance)؟

في تطوير الواجهة الخلفية (Backend)، تم التركنيز بشكل مكثف على الأداء العالي من خلال عدة ممارسات:

1. **تطبيق نمط CQRS باستخدام MediatR:**
   - تم فصل عمليات القراءة (Queries) عن عمليات الكتابة (Commands). هذا يعني أن الاستعلامات التي تجلب بيانات لا تمر بنفس التعقيد الذي تمر به عمليات الإدخال، مما يسرع بشكل كبير من عمليات استرجاع البيانات.
   - يسمح MediatR بتقليل الارتباط (Decoupling) بين الـ Controllers ومنطق الأعمال (Business Logic)، مما يجعل الكود نظيفاً وأسرع في التنفيذ وأسهل في عمل الـ Unit Testing.

2. **التحقق المسبق باستخدام FluentValidation:**
   - تم عمل Validation Pipeline (عبر MediatR Pipeline Behavior) للتأكد من صحة البيانات قبل أن تصل أصلاً لمعالجات البيانات (Handlers) أو قاعدة البيانات. هذا يوفر وقت استهلاك الموارد ويمنع الاستعلامات غير الصالحة مبكراً.

3. **الاستعلام الفعّال (Efficient Querying) مع EF Core:**
   - استخدام ميزة الـ `AsNoTracking()` في الـ Queries التي لا تتطلب تعديل البيانات (مثل جلب قائمة الأطباء)، مما يوقف تعقب الكائنات (Tracking) في الذاكرة ويزيد من سرعة جلب البيانات بنسبة كبيرة.

## 💡 أفكار لتحسين وتطوير الأداء مستقبلاً

بالرغم من أن النظام الحالي مبني بأسس قوية جداً، إلا أن هناك مجالاً للارتقاء به ليكون جاهزاً للعمل تحت ضغط عالٍ جداً (High Scalability):

1. **تطبيق التخزين المؤقت (Caching):**
   - **البيانات الثابتة:** مثل قوائم التخصصات الطبية، يمكن تخزينها في الـ Memory Cache في الـ Backend بدلاً من طلبها من الـ Database كل مرة.
   - **التخزين المؤقت الموزع (Distributed Caching):** يمكن استخدام **Redis** لتخزين بيانات الـ JWT Tokens النشطة أو استعلامات العيادة المتكررة لتسريع زمن الاستجابة لمستوى الميلي ثانية.

2. **تحسين قواعد البيانات:**
   - إضافة **Indexes** (فهارس) على الأعمدة الأكثر استخداماً في البحث (مثل أرقام هواتف المرضى أو أسماء الأطباء) لتسريع عمليات الـ SELECT.
   - تفعيل تقنية **Pagination** على مستوى قاعدة البيانات بشكل صارم للحد من كمية البيانات المسترجعة في الطلب الواحد.

3. **استخدام Dapper لعمليات القراءة المعقدة:**
   - مع أن EF Core ممتاز وسريع، إلا أن إضافة **Dapper** (Micro ORM) للـ Queries الخاصة بالتقارير والإحصائيات المعقدة سيعطي أداءً أسرع بكثير لأنه يتعامل مع SQL بشكل مباشر بدون الـ Overhead الخاص بـ EF Core.

4. **معالجة العمليات في الخلفية (Background Jobs):**
   - المهام التي تأخذ وقتاً (مثل إرسال رسائل بريد إلكتروني للمرضى للتذكير بالمواعيد) يمكن نقلها لمعالجة خلفية باستخدام مكتبات مثل **Hangfire** أو **Quartz.NET**، حتى لا يتأخر رد الـ API على المستخدم.

## ⚙️ كيفية تشغيل المشروع محلياً

### متطلبات التشغيل:
- .NET SDK (الإصدار الأخير 9/10).
- Node.js & npm.
- SQL Server (أو LocalDB).
- Angular CLI.

### تشغيل الواجهة الخلفية (Backend):
1. افتح موجه الأوامر في مسار `src/Presentation/ClinicManagement.WebApi`.
2. تأكد من إعداد نص الاتصال (Connection String) في `appsettings.Development.json`.
3. قم بتحديث قاعدة البيانات (لتشغيل الـ Migrations) عبر الأمر:
   ```bash
   dotnet ef database update --project ../../Infrastructure/ClinicManagement.Infrastructure --startup-project .
   ```
4. شغل السيرفر:
   ```bash
   dotnet run
   ```

### تشغيل الواجهة الأمامية (Frontend):
1. افتح مسار الواجهة الأمامية `src/clinic-management-frontend`.
2. قم بتثبيت الحزم (المكتبات):
   ```bash
   npm install
   ```
3. شغل التطبيق:
   ```bash
   ng serve
   ```
4. افتح المتصفح على `http://localhost:4200`.
